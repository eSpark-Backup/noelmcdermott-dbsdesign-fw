# noelmcdermott-dbsdesign-fw
DBS Stepper Control Module Firmware
## Flashing Instructions
- Connect programmer like voltlink through the prog header.
- Unzip the provided libraries inside the following path: `C:\Users\current_user\Documents\Arduino\libraries`.
- Open your project on Arduino IDE. Select board `ESP32S3 Dev Module`, `COMXX` & partition scheme `Huge App (3MB No OTA)/1MB SPIFFS`.
- Now Build & Upload your code to the esp32.
